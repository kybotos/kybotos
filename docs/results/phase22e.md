### 0-1. 画面の案(`captures/phase22e-step0/sheet.png`)

アプリの画面(metronome)の上に帯を重ねて描いた。帯の頭はメニュー(22d)と同じ: **黒の地、題名 `Settings`(クリーム)、手引き(くすんだ緑)、右に ✕(赤)、下に中緑の線**。
帯の下端にも中緑の線を引いて、下のアプリと分ける。ラベル(= MUTE のトグル)はメニューの行と同じ形(暗い緑の地 + 左端の印)、MUTE 中は文字と印が灰。

| 案 | 行の並び | 当たり判定 |
|---|---|---|
| **A(推奨)** | `[ラベル] [数字] [バー]`。数字は右寄せで縦に揃え、バーを長く(x 150〜310、160px) | ラベル x 8〜86 = MUTE、数字 x 86〜146 = はじき / 押したまま、バー x 146〜320 = タップ / ドラッグ |
| B | `[ラベル] [バー] [数字]`。数字を右端に | バー x 90〜270、数字 x 270〜320 |
| C | `[ラベル] [行全体がバー(値の割合だけ地を塗る)]`、数字はその右端 | 行のどこでもタップ = その位置の値、数字の上ではじく |

- A を推す理由: 数字が縦に揃って読みやすく、バーがいちばん長い(1 目盛り 1.6px)。数字とバーの当たり判定が離れていて取り違えにくい。
- B は数字が右端で metronome のヘッダ右の値と位置感が近いが、バーが短くなる。C は的が大きいが、塗りが暗く値の割合が読みにくい。数字の近くを狙ってタップすると 90 台になる。

### 0-2. 決めること(推奨案)

| # | 項目 | 推奨 |
|---|---|---|
| **E1** | 配置 | **案 A** |
| **E2** | 数字の操作 | **metronome の BPM と同じ**: 上下に**はじく**(押して動かして離す)と離したときに ±1(上 = 増、16px 未満は何もしない、移動は UP の座標で測る)。**押したまま上下に 24px 以上動かして置く**と 0.4 秒後から 0.4 秒ごとに ±5、4 回続くと ±10、24px 以内に戻すと止まる(この押下では離したときの ±1 は無い)。範囲 0〜100 |
| **E3** | バーの操作 | **タップでその位置の値**(バーの左端 = 0、右端 = 100)。**押したまま左右に動かすと指に追従**して値が変わる(スクラブ。離した位置で確定)。バーの上下の端より少し外(行の高さ全体)まで当たり判定にする |
| **E4** | 変更中の表示 | 数字を押して動かしている間・バーを触っている間は、**数字を黄で点滅**(ui-conventions §4。metronome と同じ) |
| **E5** | 値を反映するとき | 押したまま / スクラブの間も**その場で音量に反映**する(今の `-` / `+` の連打と同じ。耳で合わせられるように) |
| **E6** | 手引き | 帯の頭に `flick the number, tap the bar`(くすんだ緑)を常に出す |
| **E7** | MUTE・閉じ方 | 今と同じ(ラベルのタップで MUTE、✕ と帯の外のタップで閉じる)。✕ は文字の `X` から記号 U+F00D に |
| **E8** | 連打加速の定数 | `MASTERUI_HOLD_*`(`-` / `+` の連打)と `MASTERUI_MINUS_X` などを撤去し、はじき・押したままの定数を `master_ui.h` に置く(値は metronome の仕様と同じ) |

### 0-3. ユーザーの決定(2026-10-04)

- **E1: 配置は案 B**(`[ラベル] [バー] [数字]`)。
- **形はメニューと変える**(行の箱がアプリの行と同じだとアプリに見えるため)。帯全体を線で囲み、ラベルは文字だけにする方向で
  B1〜B3(`captures/phase22e-step0/sheet-b.png`)を描き、**B2(角を落とした枠に題名と ✕ を食い込ませる、行の間に薄い区切り線)**を選んだ。
  引き出しの取っ手を足した B2-1〜B2-3(`sheet-b2.png`)から **B2-1(枠の内側の下端の中央に取っ手)**。
- **E3: スクラブあり。** **取っ手は上へ払うと閉じる**操作も入れる。
- その他(E2・E4〜E8)は 0-2 の推奨案のまま。

## ステップ 3: 確認

- **Linux**(`captures/phase22e-linux/sheet.png`。metronome を動かした状態で FIFO から注入): 上端からの下スワイプで開く →
  Master の数字を上へはじいて 50 → 51 → MP3 のバーの 70% の位置をタップして 70 → Synth のバーを 200 から左へ 60px スクラブして 29 →
  Click のラベルのタップで MUTE を解除 → 取っ手を上へ払って閉じる。
- **実機**(`captures/phase22e-device-cam/sheet.png`。シリアルから注入してカメラで撮った): メニューの `Settings` で開き、Linux と同じ操作で
  51 / 70 / 29 / Click の MUTE 解除になること、逆の操作で 50 / 35 / 100 / Click MUTE に戻ること、取っ手で閉じることを確かめた。
  metronome の実行中に上端からの下スワイプで開き、帯の外のタップで閉じることも確かめた。
- 押したままの連続変更(±5 → ±10)は注入の `drag`(動かしてすぐ離す)では起きないので、単体テストで確かめ、手の操作はユーザーの確認待ち。
- **回帰 3 本 PASS**: Linux(`captures/phase22e-linux-regress`)は highmark が 33,576 / 27,208 / 34,728 で 22d と同じ。
  実機(`captures/phase22e-device-regress/report.md`)は差分が metronome +0 ×3 / mp3player −472 / hostapi_check −176 で 22d と同じ、許容外の WARN / ERROR 0 件。
  **開始時の free_int は 150,264 → 150,240(−24 B)**。マスター設定の状態変数(的・押した y・連続変更の回数など)が増えた分の静的メモリ(.bss)で、
  しきい値(`MIN_FREE_INT` 146,000)の内側。largest_int 98,304 は不変。

### ユーザーの確認(2026-10-04)

実機で、数字の押したままの連続変更(±5 → ±10)、バーのスクラブ、取っ手を上へ払って閉じる操作を手で触ってもらい、**問題なし**。
