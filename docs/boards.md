# ボードの I/O 一覧(Waveshare ESP32-S3-Touch-LCD-2.8 / CrowPanel Advance 2.8")

ファームが対応している 2 つのボードの GPIO と、その使い方をまとめる。対象は次の 3 つ。

- ボードの部品と端子の配線。
- いまのファームがそれぞれのピンをどう使っているか。
- ピンの共用と、アナログスイッチによる切り替え。

ピン配置を見直すときや、外付けの回路(MIDI IN / OUT、電源スイッチ、戻る / ホームのボタン)を設計するときの出発点にする。

- 時点: 2026-11-02(Phase 24c の終わり。CrowPanel のホームキーと MIDI を含む)。
- **ファームの原本は `src/components/board/boards/<board>.h`**。この文書と食い違ったら、そちらが正しい。ピンを変えたら、この文書も直す。
- ボードの切り替えのしくみは `docs/architecture.md` 11-13、調査の経緯は `docs/results/phase24.md`(0-b、0-c)/ `phase24a.md` / `phase24b.md`。

**情報源**

| ボード | 情報源 |
|---|---|
| Waveshare | Waveshare wiki `ESP32-S3-Touch-LCD-2.8` のピン表。ファームで実機を使ってきた実績(Phase 0〜) |

**「ファーム」の列の記号**

| 記号 | 意味 |
|---|---|

| 設定だけ | ファームがピンを設定するが、その後の動作には使っていない |

| — | ボードで何にもつながっていない、または情報が無い |

### 2-2. 共用と切り替え

- **I2C(GPIO10 / 11)**: IMU・RTC・ヘッダの I2C が 1 本のバスを共用する。ファームは使っていない(タッチは別のバス GPIO1 / 3)。
- **SD**: SDMMC(1 ビット)と SDSPI のどちらの配線にもなっている。ファームは SDSPI を使う(PSRAM が有効なときは SDMMC のプローブを飛ばす、`CONFIG_KYBOTOS_SD_SKIP_SDMMC_PROBE`)。
- **GPIO19 / 20 と 43 / 44**: ヘッダに出ているが、それぞれ USB とログの UART0 として使っている。
- **アナログスイッチなどによる切り替えは無い。**
- **ヘッダの空きは IO15 / IO18 の 2 本だけで、どちらも MIDI に使っている。** 新しい信号を足すには、I2C(GPIO10 / 11)にエキスパンダを載せるか、未使用のピン(GPIO9 / 12 / 13 は部品とつながっている)を検討する必要がある。

## 3. CrowPanel Advance 2.8"(V1.2)

部品: ESP32-S3-WROOM-1(S3R8、フラッシュ 16MB)、ST7789 + FT6336U、NS4168 + 外付けスピーカー(J2、差動)、デジタルマイク(LMD3526B261)、ブザー、
SGM3799(アナログスイッチ)、microSD、電池の充電回路(TP4059 + 補助のマイコン STC8G1K08、ESP32 からは見えない)、BOOT / RESET、
USB-C 2 つ(CH340K → UART0 と、ネイティブ USB の「USB1」)、拡張の端子 J5〜J9。
手元の個体には **I/O 基板(rev-a)** を載せている(電源キーと自己保持、MIDI、残量計、ペダルの A/D、外付けの DAC のコネクタ。§3-4。Phase 26)。

### 3-2. 共用と切り替え

- **SGM3799(アナログスイッチ)**: **GPIO45** で、GPIO9 / 10 を「無線の拡張の SPI(MISO / SCK)」と「デジタルマイク(CLK / DATA)」のどちらにつなぐかを選ぶ。
  同時には使えない。ベンダーの無線のサンプルは GPIO45 を LOW にする。マイク側の状態はサンプルが無く、未確認。
  GPIO45 はストラッピングピンなので、リセットの瞬間に外から引かない。**いまのファームは GPIO45 を触らない**(マイクも無線も使わない)。
- **I2C(GPIO15 / 16)**: タッチ(0x38)、J7(3.3V-I2C)、J8(無線の拡張の制御)の 3 か所で共用する。プルアップ(4.7kΩ)は基板に載っている。
  J7 に足すデバイスは 0x38 と重ならないこと。プルアップを足しすぎないこと。
- **無線の拡張の端子(J8 / J9)**: GPIO0 / 1 / 2 / 3 / 9 / 10 / 46 と I2C を出している。無線のモジュールを使わなければ、汎用の I/O の候補になる。
  ただし次の 4 本はストラッピングピン: 0(BOOT)、3、45、46。9 / 10 は SGM3799 を通る。
- **UART0**: CH340K(USB-C)と J5(5V-UART0)の両方につながる。**5V を受けてよいのは J5 だけ**で、J6・J7・J9 などは 3.3V。
- **電源**: 3V3_OUT1(J6)/ 3V3_OUT2(J7)はボード側の電源の経路で、ESP32 からは制御しない。

### 3-4. I/O 基板(rev-a)

CrowPanel の J8 / J9 にソケットで載せる自作の基板(Phase 26 で確認)。J6(MIDI)と J10(電池)へは線でつなぐ。

| 機能 | ESP32 のピン / バス | 基板の部品 | ファーム(Phase 26 の時点) |
|---|---|---|---|
| 電源キー(ホームキーを兼ねる) | IO1(J9)入力 | 押しボタン → ショットキー → IO1。押している間は電池の経路も ON | **使用**(`PIN_PWR_KEY_IN`) |
| 自己保持(HOLD) | IO2(J8)出力 | IO2 → N-ch → P-ch(電池の経路)。100kΩ のプルダウン | **使用**(`PIN_PWR_LATCH`、§4) |
| 電池の経路 | — | 電池 → J1 → 逆接続の保護 → P-ch → 線で CrowPanel の J10 | HOLD が LOW の間、CrowPanel の J10 に電池はつながらない |
| MIDI IN / OUT | IO18 / IO17(J6、線) | フォトカプラ TLP2361 / トランジスタ MMBT3904 | **使用**(Phase 24c と同じ設定。IN / OUT とも確認) |
| 残量計 | I2C 0x36 | MAX17048(電池側から給電) | 応答と VERSION(`0x0012`)を確認。**電池が無くても応答し、もっともらしい電圧を返す**(充電回路の出力が見える)。**使用**(Phase 26a、`KB_BATT_SRC_FUEL_GAUGE`)。2 秒ごとに VCELL / SOC / CRATE を読む。満充電でテスターの 4.15 V に対して 4.164〜4.168 V |
| A/D(ペダル 2 本、VIN) | I2C 0x48 | ADS1115。AIN1 = ペダル 1、AIN0 = ペダル 2、AIN3 = ペダルの電源、AIN2 = VIN ÷ 2(CrowPanel 側が未実装で 0 V) | 応答と CONFIG の既定値(`0x8583`)を確認。ファームは未使用(後の段) |
| RTC | I2C 0x52 | RV-3028-C7 | **rev-a では未実装**(応答しないことを確認) |
| 外付けの DAC(ライン出力) | IO10 = BCK、IO9 = DIN、IO3 = LCK(J9) | コネクタだけ(PCM5102 のモジュールを線でつなぐ)。MCLK は使わない | 未使用(後の段。IO45 = LOW が要る) |

実測(Phase 26、USB + 電池): HOLD = HIGH で電池側 4.01 V / J10 側 4.04 V(充電中、LED 赤)、HOLD = LOW で電池側 3.91 V / J10 側 4.28 V(切り離し、LED 緑)。

## 4. 外付けの回路を設計するときの前提(いまのファームの動き)

| 項目 | いまのファームの動き | 回路で気をつけること |
|---|---|---|
| MIDI OUT | UART1、31250bps 8N1。**TXD を反転**(`uart_set_line_inverse(UART_SIGNAL_TXD_INV)`)。アイドルでピンは **LOW** | Waveshare の自作回路はトランジスタ(2SC1815)で引き込む形。反転をやめるなら `midi.cpp` を変える(ボードの記述にはまだ定数が無い) |
| MIDI IN | UART1 の RX、**反転なし**。フォトカプラ(TLP2361、トーテムポールの出力で反転型)の出力を直結 | アイドル(電流なし)で H になる回路が前提 |
| MIDI の初期化 | **CrowPanel でも起動時に UART1 を GPIO17 / 18 で初期化する**(J6 に何もつないでいなくても) | J6 の TX は起動後に LOW で出力になる |
| 電源キー / ホームキー | **Waveshare**(`KB_PWR_HOLD_ALWAYS 0`): GPIO6 は内部プルアップの入力で、LOW で押下。GPIO7 は、起動時にキーが押されていれば HIGH(自己保持、電池のとき)、押されていなければ外部の電源とみなして触らない。電池のときは長押し 2 秒で(押したまま)LOW にしてディープスリープ(電源断)。**CrowPanel + I/O 基板**(`KB_PWR_HOLD_ALWAYS 1`、Phase 26): IO2 を**起動するたびに HIGH**(キーの有無によらない。起動から約 1 秒。電池で起動するときは画面が点くまで押す)。長押し 2 秒で(押したまま)アプリを止め、バックライトを消して IO2 を LOW。押している間はキーそのものが電池の経路を保つので、**離したときに電源が切れる**。離して 1 秒後も動いていれば USB 給電中とみなし、IO2 とバックライトを戻す(ディープスリープは使わない)。どちらも短押し = 戻る、1〜2 秒 = 強制ホーム | ファームは `KB_HAS_POWER_KEY` / `KB_HAS_POWER_LATCH` / `KB_PWR_HOLD_ALWAYS` と、2 本のピンのマクロで切り替える。**ESP32 のリセット中は HOLD が LOW なので、電池だけで動いているときはリセットで電源が切れる**(固まったときに切る手段として受け入れている) |
| 充電(CrowPanel + I/O 基板) | ファームは USB の有無を読めない(VIN の検知は CrowPanel 側が未実装)。HOLD を上げて電池を充電回路(TP4059)につなぐだけ | **TP4059 は電池が一度見えなくなると完了(DONE、LED が緑)に入り、HOLD を上げても充電を再開しないことがある**。USB を挿した瞬間とリセットのたびに約 1 秒切り離されるので、**rev-a では「電池で起動してから USB を挿す」と確実に充電される**(USB で起動したときは充電されないことがある。Phase 26) |
| 戻る / ホーム | どちらもキーの短押し / 長めの押し(CrowPanel は IO1)。シリアルの `key back` も使える | |
| 電池の残量の表示(Waveshare、CrowPanel + I/O 基板) | 画面の右上に常にバッジ(`shared/battery_badge.h`)。予約は x 276〜320、y 3〜23。アプリのヘッダ右の部品はここを避ける。スクリーンセーバー・消灯の間は消える | 外付けの回路には関係しない |
| 電池電圧(Waveshare) | GPIO8 の ADC を 64 回平均して約 1.6 秒ごとに更新(`battery` コンポーネント)。残量(%)は LiPo の暫定の表 | **USB を挿すと充電の電圧が乗り、電池より約 50mV 高く読める。USB のみで電池なしだと 4.19〜4.20V(満充電の電池と区別できない)**。電池で動いているときの値が本来の電池電圧 |
| 電池の残量(CrowPanel + I/O 基板) | I/O 基板の残量計(MAX17048、I2C 0x36。タッチと同じバス)を、バッジの更新のタイマ(LVGL のタスク)から 2 秒ごとに読む。電圧 = VCELL、残量(%)= チップの SOC。**USB 給電の見え方(白抜き)は CRATE で切り替える**(+2 %/h より大 = 外部給電、−2 %/h より小 = 電池、間は前のまま。起動時は電源キーで決まる)。起動時、I2C のバスを作る前に SDA が LOW なら SCL を最大 9 回たたいて解放する(`KB_I2C_BUS_RECOVER`。残量計はリセットをまたいで動くため)。Phase 26a | **電池が無くても値が出る**(充電回路の出力が見える)。**満充電で USB を挿しても充電が始まらなければ白抜きにならない**(CRATE が動かないため)。残量計への書き込みはしていない(既定のハイバネートのまま) |
| 起動の直後 | ファームが設定するまで、ピンはリセット後の既定(多くは入力、一部は弱いプルアップ / ダウン) | 外付けの回路は、ESP32 が入力の間(リセット中・書き込み中)に誤動作しないこと |
| ストラッピングピン | GPIO0 / 3 / 45 / 46 | 外付けの回路で、リセットの瞬間に強く引かない |
| 使えないピン | GPIO19 / 20(USB)、26〜37(フラッシュ / PSRAM)、43 / 44(ログ) | |
