# Phase 22e: Settings(マスター設定)を見直す(配色と、値の変え方)

- 契約日: 2026-10-04
- 参照: `docs/results/phase21b.md` / `phase21c.md`(マスター設定とミキサーを作ったフェーズ)、`docs/results/phase22d.md`(メニューの配色)、
  `docs/apps/metronome/spec.md` §3(はじきと押したままの上下)、`docs/design/ui-conventions.md` §2(上下のはじき・押したまま上下)、
  `shared/master_ui.h` / `master_ui.c`(判定・状態・座標。両ホストで共有)、`src/components/wasm_runtime/hostapi.cpp`(実機の描画)、
  `hosts/linux/hostapi_sdl.c`(Linux の描画)、`hosts/linux/main.c`(メニューからの入口)
- 結果報告先: `docs/results/phase22e.md`

## 目的

マスター設定(画面上端からの下スワイプ、またはメニューの `Settings` で開く帯)は Phase 21b の作りのままで、
**配色が青系**(帯 `0x1a2234`、行 `0x2a3340`)、**値を `-` / `+` のボタン(長押しで連打加速)で変える**。
Phase 22b〜22d で揃えたアプリとメニュー(黒の地、ロゴの緑、値は上下のはじき)と違うので、作り直す。

## 決定済みのスコープ(2026-10-04 のユーザー指示)

- **配色をメニュー(22d)・アプリ(22b / 22c)に揃える。**
- **`-` / `+` のボタンは削除する。**
- **数字は metronome のテンポと同じ操作で変える**: 上下に**はじく**と ±1、**押したまま上下**に動かして置くと ±5 で変わり続け、続くと ±10。
- **バーをタップすると、その位置の値に直接する**(任意の値を一度で設定できる)。

## 前提(着手時にソースで確認すること)

- **P1: 判定・状態・座標は `shared/master_ui.c` に 1 本化されている**(Phase 21b)。描画だけがホストごと(実機 LVGL / Linux SDL)。
  はじき・押したまま・バーのタップの判定も `master_ui.c` に置き、両ホストで同じにする(metronome は Rust の appui + アプリ側の実装なので、C で同じ規則を書く)。
- **P2: 開いている間の入力**: `masterui_on_touch` は今 DOWN で `-` / `+` / MUTE を決め、UP で連打を止めている。MOVE は食うだけ。
  はじきは **UP の座標**で量を決める(ui-conventions §6)。**Linux のメニュー画面からは DOWN しか渡していない**(`hosts/linux/main.c`)ので、MOVE / UP も渡す。
- **P3: 項目**は Master / MP3 / Synth / Click の 4 つ(0〜100)。ラベルのタップ = MUTE のトグル(Phase 21c)。帯の外のタップと ✕ で閉じる。
- **P4: 帯はアプリのスロットを使わない**(ホストが最後に上から重ねる)。Host API / ABI は関係しない。
- **P5: 回帰のシナリオはマスター設定を通っていない**。確認は撮影と、シリアル / FIFO からの注入(`drag` は動かしてすぐ離すので、押したままの連続変更は人の操作で確かめる)。
