# Phase 26a: CrowPanel の残量計(I/O 基板の MAX17048)

(2026-11-07。Phase 26 の締めのあと、ユーザーの指示「次の残量計の実装のみ、進めておいて」を受けて Claude Code が書いた。
ユーザーが不在の間に実装とビルドまで進め、実機の確認はユーザーが戻ってから行う。)

## 目的

CrowPanel + I/O 基板(rev-a)で、残量計 MAX17048(I2C 0x36)から電池の電圧と残量を読み、
Phase 25 / 25a の電池の口(`battery` コンポーネント、右上のバッジ、シリアルの `batt`)にそのまま流す。

## 前提(Phase 26 で分かっていること)

- 残量計はタッチ(FT6336U、0x38)と同じ I2C_NUM_1(SDA 15 / SCL 16)。電池側から給電されるので、ESP32 のリセットをまたいで動き続ける。
- **電池が無くても応答し、もっともらしい電圧を返す**(充電回路の出力が見える)。値だけで電池の有無は判定できない(Phase 25 の ADC と同じ)。
- CRATE(充放電の速さ)は更新が遅い(約 1 分)。
- 充電は TP4059 の制約(roadmap U-38)があり、「電池で起動してから USB を挿す」と確実に充電される。

## 作業

### ステップ 1: 実装

1. ボードの記述に電池の値の出どころを足す: `KB_BATT_SRC`(`KB_BATT_SRC_ADC` = Phase 25 の分圧 + ADC、`KB_BATT_SRC_FUEL_GAUGE` = I2C の残量計)。
   既定は ADC(Waveshare は不変)。CrowPanel は `KB_HAS_BATT_SENSE 1` + 残量計。
2. `battery` コンポーネント: 残量計のときは、タッチのドライバが作った I2C のバスに 0x36 を足し、約 2 秒ごとに VCELL / SOC / CRATE を読む。
   - 電圧 = VCELL(78.125 µV/LSB)。残量(%)= **SOC レジスタ**(チップの ModelGauge の推定。1/256 %)。比較のためにシリアルで電圧からの表の値も出す。
   - チップへの書き込みはしない(既定の設定のまま。ハイバネートの扱いはステップ 2 の値を見て決める)。
   - 起動時に VERSION を読み、応答が無ければ電池の値を出さない(バッジは出ない)。
3. **USB 給電の推定**: CRATE が +2 %/h を超えたら「外部給電(充電中)」、−2 %/h を下回ったら「電池」に切り替える(間は前の状態を保つ)。
   起動時の値は Phase 26 のとおり(キーを押して起動 = 電池)。バッジの見え方(25a の白抜き)がこれに従う。
4. **起動時の I2C のバスの回復**: バスを作る前に SDA が LOW なら、SCL を最大 9 回たたいて STOP を出す(残量計が読み出しの途中でリセットされた場合に備える)。
   CrowPanel だけ(`KB_I2C_BUS_RECOVER`)。
5. シリアルの `batt` に出どころ(`src=adc|fg`)と、残量計のときの SOC / CRATE / 表の値を足す(既存の `mv=` `pct=` はそのまま)。

### ステップ 2: 実機の確認(ユーザーが戻ってから)

- 電池あり・電池だけで起動: `batt` の電圧がテスターの TP1 と合う(±20 mV 目安)、バッジが出る。
- 電池で起動してから USB を挿す: 約 1 分で CRATE が正になり、バッジが白抜きになる。USB を抜くと戻る。
- USB だけで起動(電池なし): 値が出ること自体は避けられない(記録する)。
- 起動直後にリセットを繰り返して、I2C が固まらない(タッチも残量計も応答する)。

### ステップ 3: 回帰と締め

- 両ボードで回帰 3 本(`MIN_FREE_INT` は変えない)。Waveshare の動きは不変。
- `docs/boards.md`、`docs/roadmap.md`(26a の行、U-40 の満充電の測定を一緒にできれば)、`docs/status.md`、`docs/results/phase26a.md`。

## 完了条件

1. CrowPanel + I/O 基板で、電池の電圧と残量がバッジとシリアルの `batt` に出る(電圧がテスターと合う)。
2. USB 給電の推定がバッジの見え方に反映される(電池で起動して USB を挿す / 抜く)。
3. 両ボードで回帰 3 本 PASS、Waveshare の動き・Host API / ABI・`.wasm` は不変。

## ゲート

- Host API / ABI と `.wasm` は変えない。
- Waveshare の動きは変えない(既定は ADC のまま。CrowPanel の記述だけで切り替える)。
- 残量計への書き込み(ハイバネートの無効化、電池のモデルの設定など)をするなら、その前にユーザーの承認を取る。
- 電池・配線・USB の抜き挿しはユーザーが行う。
