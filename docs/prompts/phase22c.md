- 契約日: 2026-10-04
- 参照: `docs/results/phase22b.md`(直前のフェーズ。metronome の骨格・配色・回帰の書き方)、
  `docs/apps/metronome/spec.md`(骨格の実例)、`docs/design/ui-conventions.md`(縦スワイプ、▶ / ■、状態の色、記号)、
  `wasm-apps/mp3player/src/lib.rs`(現状)、`wasm-apps/appui`(ジェスチャ判定)、`shared/launcher_theme.h`(配色)、
  `shared/hostapi_defs.h`(audio / fs、記号)、`scripts/device-regress.conf`(`SCENARIO[mp3player]`)、
  `docs/roadmap.md` U-26(既存アプリの操作規約の統一)、`docs/workflow.md` §3.4 / §3.6 / §3.7
- 結果報告先: `docs/results/phase22c.md`

## 目的

mp3player は Kybotos のサンプルアプリ(公開)で、metronome と並んで実機で最初に触られるアプリ。
今の画面は Phase 6 の頃の作りのまま(タイトル `MP3 player (wasm)`、`state: STOPPED` の行、曲の一覧 6 行と `^` / `v` のスクロールボタン、
PLAY / PAUS / STOP の 3 ボタン)で、Phase 22b で metronome に入れた骨格・配色・対話規約と揃っていない。

本フェーズで mp3player を作り直す。**一番の目的はアプリ表示の統一感を metronome(Phase 22b)に揃えること**。
これで U-26(既存アプリの操作規約の統一)の残り(mp3player の分)を消化する。

## 決定済みのスコープ(2026-10-04 のユーザー指示)

- **タイトルの `(wasm)` は消す**(Phase 22a / 22b の続き)。
- **`state: ...` の行は消す**(状態は記号と色で見せる)。
- **再生 / 停止は metronome と統一した記号のボタン(ステータス行の右)にする。**
- **一覧のスクロールはボタンでなく縦スワイプにする**(`^` / `v` を消す。ui-conventions §2「スクロールのためだけのボタンは置かない」)。
- **一時停止は MP3 プレーヤーとして必須。** ▶ / ■ の 2 状態の規約に、一時停止をどう載せるかはステップ 0 で決める(下の D3)。
- 配色はメニュー(`shared/launcher_theme.h`)に合わせ、背景は黒(22b と同じ)。

## 前提(着手時にソースで確認すること)

- **P1: 今の mp3player**(`wasm-apps/mp3player/src/lib.rs`、319 行、no_std、appui 不使用、`hostapi_draw_text` だけで色の無い文字)。
  - 画面: タイトルバー(`0x206050`、40px)、`state: STOPPED`(y 46)、一覧 6 行(y 68〜、1 行 22px、x 12〜282)、
    右に `^` / `v`(x 290〜312)、下に PLAY / PAUS / STOP(y 204〜236、x 12 / 74 / 136。右の 2 枠は Phase 21c で V- / V+ を外した空き)。
  - 行のタップ = 選択してすぐ再生。PLAY = 選択中の曲を頭から。PAUS = 再生中なら一時停止、一時停止中なら再開。STOP = 停止。
  - 自然終了(`FINISHED`)で次の曲へ、最後の曲なら停止。曲は最大 16(`MAX_TRACKS`)、名前は 26 文字で切る(`.mp3` も付いたまま)。
  - タッチは `EV_TOUCH_DOWN` だけを見ている(押した瞬間に反応する)。
- **P2: Host API の audio**: `hostapi_audio_play(path)` / `hostapi_audio_ctrl(PAUSE=1 / RESUME=2 / STOP=3)` /
  `hostapi_audio_get_state()`(STOPPED / PLAYING / PAUSED / FINISHED / ERROR)。**再生位置・曲の長さを取る手段は無い**
  (経過時間や進み具合のバーは出せない。下の「含まない」)。`hostapi_fs_list` はミュージックルートの `.mp3` を順に返す。
- **P3: 記号。** 実機のフォント(Montserrat 14 + LVGL 既定の FontAwesome)には **U+F04C(‖ PAUSE)、U+F048(⏮ PREV)、U+F051(⏭ NEXT)** もある
  (`lv_font_montserrat_14.c` の `unicode_list_1`)。**Linux ホストの `draw_symbol` は ▶ / ■ / ✕ / ⟲ / ♪ しか描かない**ので、
  新しい記号を使うなら Linux ホストに図形を足す(ui-conventions §4 の「新しい記号を使うときは」)。**Host API / ABI の変更ではない**(記号は文字列のバイト列)。
- **P4: 回帰。** `SCENARIO[mp3player]="expect state: STOPPED; tap 40 220; expect state: PLAYING; wait 2; tap 164 220; expect state: STOPPED"`。
  `state:` の行を消すので、**再生中かどうかは記号のバイト列で見る**(22b の F3: `texts` は非 ASCII を `\xNN` で出し、`expect` でそのまま一致する)。
  `EXPECT_DELTA[mp3player]=-36` / `REPEAT_OVERRIDE[mp3player]=1`(U-23 の一度きりの確保)は、再生の経路が変わらなければそのまま。
- **P5: 試験用の曲は 3 つ**(`hosts/linux/sdcard/music/`、実機の SD も同じ 3 つ)。**3 曲では一覧がスクロールしない**ので、
  スワイプの確認には曲を一時的に増やす(複製でよい。repo には足さない。実機の SD に置いたものは確認後に消す)。
- **P6: 描画スロット(text 80 / rect 80、座標で引かれて解放されない)。** 一覧は行の座標が固定なので、スクロールしても枚数は増えない。
  スワイプを「指に追従して px 単位で動かす」形にすると、行の y が毎回変わってスロットを使い切る。**行単位で動かす**(下の D5)。
- **P7: appui** は app-sequencer がタグ(`appui-v0.1.0`)で依存している。足すだけの変更なら壊さない。
  22b の D6 で「配色の値は、mp3player を作り直すときに `appui` へ `theme` として移す(使う側が 2 つになってから共有する)」と決めてある。
- **P8: mp3player の `.wasm` を作り直すので、Linux の highmark の基準(19,112)を取り直す**(22b の metronome と同じ扱い)。
  metronome / hostapi_check は、appui の `theme` に移すかどうか(D8)で変わる。

## 論点(ステップ 0 で決める)

### 一時停止(D3)の案

ui-conventions の再生 / 停止は **▶(緑、押すと始まる)/ ■(赤、押すと止まる)**の 2 状態で、**記号は「押すと何が起きるか」**を表す。
MP3 には「止める(頭に戻る)」と「一時停止(続きから)」の 2 つがあるので、どこかで 3 つ目を置く必要がある。

| 案 | ステータス行の右 | 停止 | 統一感 | 簡素さ |
|---|---|---|---|---|
| **A(推奨)** | 右端 = **▶ / ‖ のトグル**(停止中・一時停止中は ▶、再生中は ‖)。その左に **■**(停止中は出さない) | ■ のタップ | 右端が「そのアプリの主操作のトグル」で揃う(metronome は ▶ / ■、mp3player は ▶ / ‖)。■ は赤で意味も同じ | 記号 2 つ。一般的な音楽プレーヤーと同じで迷わない |
| B | 右端 = **▶ / ■**(metronome と完全に同じ)。再生中・一時停止中だけ、その左に **‖ / ▶(再開)** | ■ のタップ | 右端の記号と位置が全アプリで同じ | 一時停止中に ▶ が 2 か所に出る(再開と頭から)。頻度の高い一時停止が右端に無い |
| C | 右端 = **▶ / ‖ のトグルだけ** | **‖ の長押し**(壊す操作は長押し。§2)。または停止を持たず、別の曲は行のタップで選ぶ | 記号の意味は規約どおり | 最も簡素。ただし停止が見えない |
| D | 右端 = ▶ / ■。**一時停止は再生中の曲の行のタップ**(もう一度タップで再開) | ■ のタップ | ステータス行は metronome と同じ | 一時停止が見えない。行のタップ = 再生、と意味がぶつかる |

- 案 A・B は ‖(U+F04C)を Linux ホストの `draw_symbol` に足す(P3)。‖ の色は決める(規約の緑 / 赤 / 黄は使わず、クリームか若葉を推奨)。
- **ui-conventions の §4「状態の色」と §2「専用ボタンを置いてよい条件」に、一時停止を足す**(どの案でも一般則として書く)。
- 当たり判定は metronome と同じくステータス行の右(x 240〜320)を広く取る。案 A・B で記号が 2 つになるので、2 つの的の境目を決める。

### そのほかの決めること(D1〜D10)

- **D1: 画面の骨格。** 推奨: metronome と同じ**ヘッダ(26px、濃緑、左 `MP3 Player`)+ ステータス行(24px)+ 黒の本体**。
  本体(y 50〜240、190px)を一覧にする。題名の表記(`MP3 Player` / `MP3` / `Music`)も決める。
- **D2: ヘッダ右とステータス行の左に何を出すか。** `state:` の行を消した代わりに、例:
  ヘッダ右 = **曲の番号 `2/3`**(回帰で読める手がかりにもなる)、ステータス行の左 = **今の曲名**(一覧をスクロールして見えなくなっても分かる)。
  停止中の手引き(metronome の `flick up / down` に相当)を出すかも決める(例: 曲が収まらないときだけ `swipe`)。
- **D3: 一時停止**(上の案)。
- **D4: 一覧の行。** 行の高さ(今の 22px のままで 8 行 / 指で押しやすく 30〜38px で 5〜6 行)、配色(メニューの行と同じ中緑にするか、
  黒の地に文字だけにするか)、**今の曲の示し方**(行頭の記号 ▶ / ‖、文字色、背景色)、**`.mp3` の拡張子を出さない**(22a のメニューと同じ)、
  長い名前の切り方(文字数で切る / 末尾を `...`)。
- **D5: スクロール。** 推奨: **appui の `Gesture` の縦スワイプ(`Scroll { dy }`)を、行の高さごとに 1 行ずつ送る**(P6。指への追従は行単位)。
  スクロールの位置を示すもの(スクロールバー)を置くかも決める。
- **D6: タップの意味。** 推奨: **行のタップ = その曲を頭から再生**(今と同じ)。**押したときではなく離したときに**(スワイプと区別するため。appui の `Tap`)。
  **再生中の曲の行のタップ**を何にするか(頭から / 何もしない / 一時停止 = 案 D)。
- **D7: 曲の終わり。** 今と同じ(次の曲へ、最後なら停止)を推奨。最後の曲のあと先頭へ戻す・1 曲リピート・シャッフルは含まない。
  前 / 次の曲へ移る操作(⏮ / ⏭、または横スワイプ)を置くかも決める(推奨: 置かない。行のタップで足りる)。
- **D8: 配色の置き場所。** 推奨: **`appui` に `theme` を足し**(22b D6 の予定)、metronome もそれを使うように直す
  (metronome の `.wasm` も作り直しになるので highmark を取り直す)。代案: mp3player の中の定数にして、共有は後回し。
- **D9: 曲が無いとき・再生に失敗したとき。** 今は一覧の 1 行目に `no mp3 files in music dir`、失敗は `state: ERROR` と `rc: -1`。
  新しい画面での出し方(本体の中央に 1 行、ステータス行に赤で `play failed` など)。
- **D10: 回帰のシナリオ。** 例: `expect 1/3; expect \xef\x81\x8b; tap <▶>; expect \xef\x81\x8c; wait 2; tap <‖>; expect \xef\x81\x8b; tap <▶>; expect \xef\x81\x8c; tap <■>; ...`
  (▶ → ‖ → 一時停止 → 再開 → 停止)。**行のタップで別の曲を鳴らし、ヘッダの番号が変わる**ところも見る。
  記号が同時に 2 つ出る案(A・B)では、`expect` が画面のどこかに含まれるかしか見ないので、**どちらの記号が出ているか**で状態が決まるようにする
  (例: 案 A なら ▶ と ‖ は同時に出ない)。

## ゲート(必須)

1. **ステップ 0 の設計メモ(画面の案と D1〜D10 の決定)をユーザーが承認するまで実装しない。**
   画面の案は Linux のスクリーンショット(試作)か、座標を書いた図で見せる(22b と同じく `captures/phase22c-step0/`)。
2. **Host API / ABI は変えない。** Linux ホストの `draw_symbol` に記号の図形を足すのは可(P3)。
3. **回帰 3 本(実機・Linux)が PASS。** mp3player のシナリオは新しい画面に合わせて書き直す(conf のスキーマは変えない)。
   **hostapi_check の `.wasm` は再ビルドしない**(highmark 不変)。metronome は D8 次第(作り直すなら highmark を取り直して記録)。
4. **描画スロットは text 80 / rect 80 の内側**(使った枚数を記録する)。
5. **app-sequencer が壊れない**(appui を変えた場合、横に置いた kybotos でビルドが通ること)。
6. 公開の repo なので、**Sequencer のコード・設計の中身は書かない**(ui-conventions に書かれている語彙の範囲で参照する)。

## スコープ

### 含む

#### ステップ 0: 設計メモ(実装なし・承認ゲート)

- 着手時の確認(P1〜P8 をソースで確かめる。特に appui の `Scroll` の返り方、`Tap` が離したときに返ること、‖ の実機の字形)。
- 画面の案(一時停止の案 A〜D のうち 2〜3 つ、停止中 / 再生中 / 一時停止中 / 曲が無いとき)を描いて、D1〜D10 を決める。
- 描画スロットの見積もり。

#### ステップ 1: 画面の骨格と配色

- ヘッダ・ステータス行・黒の本体、タイトル、配色(D8 の置き場所)。`state:` の行と PLAY / PAUS / STOP のボタンを外す。
- 再生 / 一時停止 / 停止の記号(D3)。Linux ホストの記号の図形。

#### ステップ 2: 一覧とスクロール

- 行の見た目(D4)、今の曲の示し方、拡張子を出さない。
- appui の `Gesture` に置き換え(タップは離したとき、縦スワイプで行単位のスクロール。D5 / D6)。
- 曲を一時的に増やして(P5)、スクロールの両端・自然終了で次の曲が画面外に出たときの追従を確かめる。

#### ステップ 3: 確認

- **Linux のスクリーンショットで、停止中 / 再生中 / 一時停止中 / スクロール中 / 曲が無いとき**を残す(`captures/phase22c-*`)。
- **実機で写真か動画**(§3.3。シリアルから操作を注入して録ってよい)。**音はユーザーが聞いて確認**(一時停止・再開で続きから鳴るか)。
- **回帰 3 本(実機・Linux)PASS**、mp3player の highmark の取り直し、hostapi_check の highmark 不変(metronome は D8 次第)。

#### ステップ 4: 文書

- `docs/results/phase22c.md`(画面の決定と理由、使ったスロット数、回帰の結果)。
- **mp3player の仕様書を新しく置く**(`docs/apps/mp3player/spec.md`。metronome と同じ形)。
- `docs/design/ui-conventions.md`: 一時停止の記号と色、単画面アプリの一覧(縦スワイプの行単位の送り)など、一般則として出たものを足す。
- `docs/roadmap.md`: 22c の行、**U-26 の mp3player の部分を消化**したことを書く。
- 締めで `docs/workflow.md` / `docs/lessons.md` への反映の要否を確認する。

### 含まない

- **経過時間・曲の長さ・シーク**(Host API に再生位置が無い。足すなら別のフェーズで Host API の追加として扱う)。
- 曲のリピート・シャッフル・プレイリスト、フォルダの階層、曲の情報(ID3 タグ)。
- 曲の数の上限(16)の引き上げ(要るなら D4 / D5 の結果を見て別に扱う)。
- 音量の UI(Phase 21c で装置のミキサーへ移した)。
- MP3 と内蔵音源の切替の雑音(U-21)。
- 設定・最後に聞いた曲の持ち越し(U-24)。

## 完了条件

1. mp3player が新しい画面で動く: タイトルに `(wasm)` が無い、`state:` の行が無い、ステータス行の記号で再生 / 一時停止 / 停止、
   縦スワイプでスクロール、配色は metronome と同じ骨格(実機・Linux)。
2. 一時停止から再開すると続きから鳴る(ユーザーが聞いて確認)。自然終了で次の曲へ進む。
3. **回帰 3 本(実機・Linux)PASS**。mp3player の highmark を取り直して記録、hostapi_check は不変。
4. **Host API / ABI 不変**。描画スロットの使用枚数を記録。
5. 仕様書 `docs/apps/mp3player/spec.md` と記録 `docs/results/phase22c.md`。
