# mp3player 仕様

- 版: Phase 22c(2026-10-04)。経緯と判断の理由は `docs/results/phase22c.md`
- ソース: `wasm-apps/mp3player/src/lib.rs`(no_std、`appui` の `Gesture` と `theme` を使う)
- 操作の語彙の原本は `docs/design/ui-conventions.md`。本書はこのアプリ固有の画面と操作を決める。
  骨格(ヘッダ + ステータス行 + 黒の本体)と配色は metronome(`docs/apps/metronome/spec.md`)と同じ(`appui::theme`)

## 1. 機能

- ミュージックルート(実機 `/sdcard/music`、Linux `hosts/linux/sdcard/music`)の `.mp3` を、ホストの列挙順に最大 16 曲まで一覧に出す。
- 再生 / 一時停止 / 停止。一時停止からは続きから鳴る。曲が終わると次の曲へ、最後の曲なら停止する。
- 経過時間・曲の長さ・シークは無い(Host API に再生位置が無い)。リピート・シャッフルも無い。
- 音量は装置のミキサー(MP3 チャネル)。アプリに音量の UI は無い。
- 画面は 1 枚。`app_key` は export しない(HW キー短押し = アプリ終了。ui-conventions §5)。
- 設定・最後に聞いた曲は持ち越さない(起動のたびに 1 曲目を選んだ停止中)。

## 2. 画面(論理座標 320×240)

| 領域 | 位置 | 中身 |
|---|---|---|
| ヘッダ | y 0〜26、濃緑 | 左 `MP3 Player`(クリーム)、右 = **選んでいる曲の番号 `2/12`**(右端 x 312 にそろえる。曲が無いときは `0/0`) |
| ステータス行 | y 26〜50 | 左 = **停止中だけ手引き `tap a song, swipe to scroll`**(くすんだ緑)、再生に失敗したときは赤で `cannot play: <曲名>`。右端(x 292)= **▶ / ‖**、その左(x 258)= **■** |
| 本体 | y 50〜240、黒 | 曲の一覧(27px × 7 行)。曲が無いときは `no mp3 files in /sdcard/music` を 1 行 |

**ステータス行の記号**(記号は「押すと何が起きるか」。ui-conventions §4):

| 状態 | x 258 | x 292 |
|---|---|---|
| 停止中 | (出さない) | ▶ 緑 |
| 再生中 | ■ 赤 | **‖ クリーム** |
| 一時停止中 | ■ 赤 | ▶ 緑 |
| 曲が無い | (出さない) | ▶ 暗い灰(押せない) |

**一覧の行**: y 52 から 27px ごと(行の高さ 24 + 隙間 3)、x 4〜310(曲が 7 曲を超えるときは x 4〜310 の幅 306、右端 x 313〜317 にスクロールの位置の帯)。

- 行の地は `0x101a14`、**選んでいる曲の行は `0x24483a`**。文字はクリーム(x 28)。
- **今の曲の行頭(x 10)に記号**: 再生中 = 若葉の ▶、一時停止中 = クリームの ‖、停止中は無し。
- 曲名は**拡張子 `.mp3` を取って**出す。行に入らない名前は**字幅で切って末尾を `..`** にする
  (字幅は実機の Montserrat 14 と Linux の DejaVu の大きいほう。UTF-8 の途中では切らない)。
- スクロールの位置の帯: 地 `0x101a14`、つまみ `0x3e6648`(高さは 7 / 曲数の割合、最小 12px)。

## 3. 操作

| 押す場所 | 操作 | 結果 |
|---|---|---|
| ステータス行の右 x 276〜320 | タップ | 再生中なら一時停止、一時停止中なら続きから、停止中なら**選んでいる曲を頭から** |
| ステータス行の x 240〜276 | タップ | 再生中・一時停止中なら停止(停止中は ▶ と同じ) |
| 一覧の行 | タップ | **その曲を選んで頭から再生**(再生中の曲の行でも頭から) |
| 一覧 | 縦スワイプ | **行単位で送る**(上へはらうと後ろの曲が出る。押下からの移動 27px で 1 行)。両端で止まる |

- タップは**離したとき**に効く(スワイプと区別するため。appui の `Tap`)。長押しのまま離してもタップと同じ(点滅しない)。横の移動は何もしない。
- 一覧は指に px 単位では追従しない(描画スロットが座標で引かれるので、行の y を動かすとスロットを使い切る)。
- 曲が終わって次の曲へ進んだとき、その行が一覧の外なら、見える位置まで送る(ui-conventions §3.5「再生中の要素は追う」)。
- 再生に失敗した曲(play が失敗、または状態が ERROR)は、ステータス行に赤で出して止まる(次の曲へは進まない)。次の ▶ / ■ / 行のタップで消える。

## 5. 回帰

`scripts/device-regress.conf` の `SCENARIO[mp3player]`(実機・Linux 共通)。▶ → ‖(再生)・■ が出る → 一時停止で ▶ → 再開で ‖ →
2 曲目の行のタップでヘッダが `2/…`(曲の総数は SD の中身で変わるので、番号の頭 `f3f1e4 2/` だけを見る) → ■ で停止し手引きが戻る、を**記号の位置と色**(`expect 292 30 40e070 \xef\x81\x8b` など)で確かめる。
一時停止・再開の音(続きから鳴るか)は回帰では分からないので、人が聞いて確かめる。
