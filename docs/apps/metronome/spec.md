# metronome 仕様

- 版: Phase 22b(2026-10-04)。経緯と判断の理由は `docs/results/phase22b.md`
- ソース: `wasm-apps/metronome/src/lib.rs`(no_std、`appui` の `Gesture` を使う)
- 操作の語彙の原本は `docs/design/ui-conventions.md`。本書はこのアプリ固有の画面と操作を決める

## 1. 機能

- BPM 40〜240(既定 120)、拍子 = 分子 1〜16 / 分母 2・4・8・16(既定 4/4)、▶ / ■。
- **拍は分母の音符**(6/8 は 8 分音符で 6 回鳴る)。BPM は常に 4 分音符の基準(`us_per_quarter`)。
- 音は内蔵音源(SYNTH)の note 34(小節頭)/ 33(他の拍)。音量は装置のミキサーの Synth チャネル。
- 画面は 1 枚。`app_key` は export しない(HW キー短押し = アプリ終了。ui-conventions §5)。
- 設定は持ち越さない(起動のたびに 120 / 4/4)。

## 2. 画面(論理座標 320×240)

| 領域 | 位置 | 中身 |
|---|---|---|
| ヘッダ | y 0〜26、濃緑 `0x183c29` | 左 `Metronome`(クリーム `0xf3f1e4`)、右 `120bpm 4/4`(x 200 / 268。本体と同じ並び) |
| ステータス行 | y 26〜50、`0x0b140f` | 左 = 停止中だけ手引き `flick up / down`(くすんだ緑)、右 = ▶(緑)/ ■(赤)(x 292) |
| 本体 | y 50〜240、黒 | 左 = BPM の巨大な数字、右 = 拍子の分数、下端 = 拍の枠 |

- **BPM**: 7 セグメント 3 桁(1 桁 54×104、画の太さ 12、x 10・y 62)。上の桁の 0 は空白。
- **拍子**: 分子(y 60)/ 線(x 228・y 114・84×4)/ 分母(y 124)。各 2 桁(1 桁 30×46、太さ 7、x 232)。
- **拍の枠**: y 184〜230 に分子の数だけ 1 段で並べる(全体の幅 304px で一定、1 枠は最大 72px、8 拍までは間隔 4px、9 拍以上は 2px)。
  再生中は今の拍の枠を点ける(1 拍目は橙 `0xf0a040`、他は若葉 `0x8fd18b`、消灯は `0x1c2620`)。**拍の番号は 8 拍まで**枠の中に出す。
- 値を変えている間は、その値(BPM はヘッダの `120bpm` も、拍子は変えている方とヘッダの拍子)を**黄とクリームで 200ms ごとに点滅**(ui-conventions §4)。

## 3. 操作

| 押す場所 | 操作 | 結果 |
|---|---|---|
| ステータス行の右(x 240〜320) | タップ | 再生 / 停止 |
| 本体の左(x < 215)、ヘッダの `120bpm` | 上下に**はじく** | BPM ±1(上 = 増) |
| 同上 | **押したまま**上下に 24px 以上動かして置く | 0.4 秒後から 0.4 秒ごとに ±5、4 回続くと ±10。24px 以内に戻すと止まる |
| 本体の右、線(y 116)より上 | 上下にはじく | 分子 ±1 |
| 本体の右、線より下 | 上下にはじく | 分母を隣の値へ(2 ⇄ 4 ⇄ 8 ⇄ 16) |

- **はじき** = 押して、すっと動かして離す。**値は離したときに 1 回だけ**変わる。押下から離すまでの上下の移動が 16px 未満なら何もしない。
  移動は UP の座標で測る(MOVE は 8px 未満が間引かれるので、最後の数 px は UP にしか入らない。ui-conventions §6)。
- 押したままで BPM を変えた押下では、離したときの ±1 は足さない。
- 拍子の当たり判定は拍の枠の高さまで含める(拍の枠に操作は無い)。左右の移動は使わない。
- 拍子のはじきに「押したまま」の連続変更は無い(範囲が狭いので 1 段ずつ)。

## 4. 演奏中の変更

- **BPM**: 次の拍の頭の song tick にテンポを書く(小節はやり直さない)。同じ拍の間の変更は同じ at_tick の上書きなので、エントリは 1 拍に 1 件。
- **拍子**: 小節をやり直す(stop → `tempomap_clear` → at_tick=0 の初期値 → start)。外の MIDI 機器には Stop / Start が出る。
- 再生の開始も同じ手順。供給は `seq_write` で 2 小節先まで。

## 5. 描画スロット(text 80 / rect 80)

| 要素 | rect | text |
|---|---|---|
| ヘッダ・ステータス行・本体の背景 | 3 | — |
| BPM(100 の位は「1」「2」だけなので f を除く 6 画 + 7 + 7) | 20 | — |
| 拍子(10 の位は「1」だけなので 2 画 + 7、× 分子・分母)+ 線 | 19 | — |
| 拍の枠(左端をそろえた塗り重ねの層 16 拍 × 2。拍子によらず一定) | 32 | — |
| 題名・ヘッダの BPM・ヘッダの拍子・手引き・▶ / ■ | — | 5 |
| 拍の番号(1〜8 拍の位置、計 36 か所) | — | 最大 36 |
| 計 | **74 / 80** | **最大 41 / 80** |

- 拍の枠は位置が拍子で変わるが、スロットは座標で引かれて解放されないので、枠ごとに矩形を置くと拍子 1〜16 の全部で 136 か所になり入らない。
  画面の左外(x = −1, −2, …)を起点にした層を、最後の枠から順に「その枠の右端までの色付きの層」「その枠の左端までの黒の層」と重ねて描く。

## 6. 回帰

`scripts/device-regress.conf` の `SCENARIO[metronome]`(実機・Linux 共通)。BPM のはじき(±1)、▶ / ■、再生中の分子・分母のはじきを、
ヘッダの文字(`121bpm`、`5/4` など)と記号のバイト列(▶ `\xef\x81\x8b` / ■ `\xef\x81\x8d`)で確かめる。
押したままの連続変更は注入の `drag`(動かしてすぐ離す)では起きないので、人の操作で確かめる。
操作をひととおり流して録画で見るときは `scripts/metronome-demo.conf`。
